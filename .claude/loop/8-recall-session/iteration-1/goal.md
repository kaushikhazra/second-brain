# 8 — the owner recalls a past session by regex

## Goal

> Every acceptance criterion in GitHub issue #8 holds against this repo's `/recall-session`:
> a regular expression searches the Claude Code transcripts of THIS brain's project only,
> returns session id, date, project and an excerpt per match, newest first, with a
> configurable and stated default context; a session and a slice can be expanded; no
> match, an invalid regex, a missing directory and an unparseable file are each reported
> in the owner's terms; the skill reads and writes nothing; it works with synaptra
> unreachable; and a check exists for each criterion that fails when the behaviour is
> removed.
