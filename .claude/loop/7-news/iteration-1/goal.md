# 7 — the owner reads the day's news, if the owner switched it on

## Goal

> Every acceptance criterion in GitHub issue #7 holds against this repo's `/news`: the
> habit is asked about once per fresh brain and once per `VERSION` change through the
> activation record from #6, switched with `/news on|off|status`; when active it runs
> once a day after `/session-start`; each item is one bold headline and one verified link
> and nothing else; the keyword scope is one owner-edited file; sources are searched live;
> YouTube is included only with keys in `.env` and says so in one line otherwise; a failed
> source is named rather than passed off as a quiet day; keep, save or preserve appends to
> `reading-list.md` with no checkbox or due date; and a check exists for each criterion
> that fails when the behaviour is removed.
