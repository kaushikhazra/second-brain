# 5 — the brain reshapes its memory while asleep, never without a rollback

## Goal

> Every acceptance criterion in GitHub issue #5 holds against this repo's `/dream`: no
> reshaping starts without a backup whose row count matches the live store; every
> archive, retype and relation goes through the memory skills; the two boot lists and the
> most recent handoff are never touched by a dream; the heartbeat cron is stopped before
> and running after; an abort at any step leaves the store as it was; the dream runs only
> when the owner asks and never during an active conversation; and a check exists for
> each criterion that fails when the behaviour is removed.
