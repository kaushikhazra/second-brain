# 3 — the brain wakes holding the self and the recent memory it closed with

## Goal

> Every acceptance criterion in GitHub issue #3 holds against this repo's skills: the
> brain keeps two lists in synaptra, a self map and a surface map, each one memory
> carrying one reserved tag and holding full uuids only; `/session-start` fetches both by
> tag and loads what they point at, then the most recent handoff; `/session-end` stores an
> episodic handoff, kills its crons and runs `verify_memory.py` over both lists and the
> conformance scan; `/init-brain` seeds the lists for a new brain and leaves them alone for
> a restored one; and a check exists for each criterion that fails when the behaviour is
> removed.
