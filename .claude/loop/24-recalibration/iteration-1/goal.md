# 24 — the brain recalibrates when the model underneath it changes

## Goal

> Every acceptance criterion in GitHub issue #24 holds against this repo: the brain
> records and reads the model running it; shipped file context carries no unbounded
> dispositional instruction; the memory pass flags exactly three defect classes and
> archives rather than deletes, behind a verified backup; the release, boot and manual
> triggers each reach `/update`; upgrade and downgrade select different paths from a
> declared model ordering; `persona.md` and `user.md` change only on confirmation;
> every write is reversible and logged; and both boot lists are evaluated **as sets**,
> with flagging removing an id from the list and never from the store.
