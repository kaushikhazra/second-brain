# 46 — dream cycle

## Goal

> Every acceptance criterion in GitHub issue #46 holds against this repo, proven by a
> check that fails when the behaviour is removed: the owner switches a small dream cycle
> on and off, sets its batch size and reads its status; the heartbeat runs exactly one
> batch on a quiet beat while it is on and never while it is off, never in the same beat
> as curiosity and never while the owner is in conversation; every cycle logs what it did
> and the backlog count goes down; the switch, batch size and progress survive a restart
> and an `/update`.
